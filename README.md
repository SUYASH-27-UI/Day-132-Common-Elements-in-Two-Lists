# Python Day 132 - Common Elements in Two Lists

This Python program finds the elements that are present in both lists.

## Example

First list:
```text
[10, 20, 30, 40, 50]
```

Second list:
```text
[30, 40, 50, 60, 70]
```

Output:
```text
Common elements: [30, 40, 50]
```

## Concepts Used

- Lists
- `for` loop
- `if` statement
- `in` operator
- `append()` method

## How It Works

The program checks each element of the first list against the second list. If an element exists in both lists, it is added to the `common` list.
